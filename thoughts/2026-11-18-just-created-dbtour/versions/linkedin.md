A good internal idea doesn't have to stay internal.

In 2020 I wrote a small tool for me and my team. It read our SQL Server databases and wrote their schemas as Markdown, hooked to an internal blog so we could search every project's schema in one place.

It worked, for us. It never went further. That is where my tools usually stop.

This month it became dbtour: schema docs for your database, kept in your repository, for people and agents. It reads the catalogue, never the rows.

Where did AI-assisted development help most? SQLite, the database I use the least. And the plugs into other tools: an MCP server, a Claude Code plugin, a skill.

What AI did not do is decide. Several iterations, a lot of testing and verification, and using it every day did that.
