It worked for me. Now it works for you.

In 2020 I wrote a small tool for my own projects. It read SQL Server databases and wrote their schemas as Markdown, hooked to a blog so I could search every project's schema in one place. A few close colleagues used it too.

It worked. It never went further. That is where my side projects usually stop.

This month it became dbtour: schema docs for your database, kept in your repository, for people and agents. It documents the structure from the catalogue, and reads the data only read-only, if you ask it to.

Where did AI-assisted development help most? SQLite, the database I use the least. And the plugs into other tools: an MCP server, a Claude Code plugin, a skill.

What AI did not do is decide. Several iterations, a lot of testing and verification, and using it every day did that.
