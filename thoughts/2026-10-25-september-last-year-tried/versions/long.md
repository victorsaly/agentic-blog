# Same idea, a year later

## The idea

In September last year I tried to build a game with my son. The idea came from him, so we recorded it. Then we started to build.

It was a retro, dice-based, educational strategy game. You had different types of people. From their capabilities they earned money and won things. We called it WorldLeadersGame. The code is here: https://github.com/victorsaly/WorldLeadersGame

## How it started

It started really well.

I wanted the AI to drive the development, so I used only Copilot. That was the experiment.

## Where it stopped

The AI was not able to answer issues properly. It kept shifting, or forgetting, the original request and orders. It did not have as many skills as today, and the model was not clever enough to complete the task.

After three to four weeks we decided it was not capable of what we wanted. It was a shame. But the idea is still there.

## What I think today

If I tried it now, I am almost certain we would get a better result. I see two reasons.

The first is the model. The coding standard has improved compared to a year ago, across most LLMs. Claude in particular has shown a better approach.

The second is me. I understand much better how much leverage to give the AI. I know how to organise my questions and my reviews to get the result I want.

## This blog is the proof of the feeling

We started two days ago. It already has more than 12 agents. It has a database, and a web interface to talk to. It builds the blog automatically, without any major issues.

115 pull requests have been created so far. I review each one. The pull request gives me images, and I compare before and after. That is how I understand what changed.

Everything you see in this studio and blog is generated by agents and automations that work together. It is a completely different era. How it all fits together is explained here: https://blog.victorsaly.com/how-it-works

## What comes next

This is a feeling, and a feeling is not proof. I will prove the transformation by running the original project again.
